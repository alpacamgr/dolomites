# 0001 - Record architecture decisions

Date: 2026-09-05 - Status: accepted

## Context

The project spans geology, data licensing, and web engineering. Decisions made early (scope, data backbone, rendering stack) will be questioned later. We want the reasoning preserved.

## Decision

We record significant decisions as short Markdown files in `docs/decisions/`, numbered sequentially, using the sections Context, Decision, Consequences. Status is one of proposed, accepted, superseded.

## Consequences

Small overhead per decision; much less re-litigation later.
