# Assets

- `images/` - photos and figures. Every file has a sidecar `<name>.md` with: source URL, author, license, attribution text, and what it shows.
- `figures-redrawn/` - our own vector redrawings (SVG) of published figures. Sidecar `<name>.md` records the original paper, figure number, license, and every simplification we made. Only figures whose license permits derivatives are redrawn.
- `icons/` - UI icons. Record the icon set and license in `icons/LICENSE.md`.

No asset without a sidecar. If the license is unknown, the asset does not belong here.
